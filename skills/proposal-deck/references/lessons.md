# Lessons from the owner

Every correction the owner or user gives on a deck goes here as a standing rule, with the date
and the deck it came from. Read this file before every deck. When a lesson is about wording or
rules for all client files, also add it to `../../proposal-shared/references/house-rules.md`
(section 10 for banned terms, which the gate reads).
